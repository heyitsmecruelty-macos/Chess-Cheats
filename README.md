# Venice Chess Coach

A local Chrome extension that analyzes games on chess.com and lichess, suggests
moves, and explains positions.

## Download and install

1. Download `Chess-Coach-2.5.0.zip` from the
   [latest GitHub release](https://github.com/heyitsmecruelty-macos/Chess-Cheats/releases/latest)
   and extract it.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted `Chess Coach Extension` folder.
4. Open a game on chess.com or lichess, set your rating, and start coaching.

The extension runs locally and does not send game data to a server.
